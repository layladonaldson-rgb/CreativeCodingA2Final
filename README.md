# CreativeCodingA2Final

## Perlin Noise Flow Fields - re-creating Van Gogh's 'Starry Night'.

The aim of this project is to address an artistic challenge. I’ve spent time skimming resources on creative coding and found myself drawn to understanding the ways Perlin Noise can be utilised to create artworks. This field has many examples, however the examples I have found resemble continuous patterns across the canvas - I challenge myself to appropriate Van Gogh’s “The Starry Night” using a variety of techniques to create an original artwork.
